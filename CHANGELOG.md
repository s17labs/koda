# Changelog

## [0.1.3] - 2026-10-28

- Improve dialog backgrounds, borders, margins, title spacing and button placement. Long button labels stack when needed, and two-button dialogs have one primary action.
- Polish settings with a larger back arrow, matching status-bar background, custom selection indicators and an updated About Koda dialog.
- Use descriptive font-size labels and improve Slovak (Slovenčina) translations and language naming.
- Fix editor scrolling vertically, horizontally and diagonally, including wrapping, resizing and caret visibility.
- Add continuous edge scrolling while selecting text with the keyboard open or closed, using standard teardrop handle shapes and frame-based drag updates.
- Preserve the viewport after selection and apply the final drag movement when releasing a long press.

Signed APKs are provided for arm64-v8a (most current devices) and armeabi-v7a (older 32-bit devices). Requires Android 8.0 or newer.

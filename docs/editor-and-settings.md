# Editor and settings

Koda uses a fixed dark palette, including when Android is in light mode.

## Editing and scrolling

The editor scrolls vertically through a document. With **Wrap Lines** off, long lines extend horizontally and can be scrolled sideways or diagonally. With wrapping on, lines fit the viewport and horizontal scrolling is disabled.

The viewport adjusts when the keyboard, screen size or font size changes and brings the caret into view as you edit. Switching tabs resets the viewport to the top-left and stops any ongoing fling. Mouse wheel scrolling, Shift+wheel horizontal scrolling and accessibility scroll actions are supported.

## Settings

Choose a font family and one of six font sizes: **Extra small**, **Small**, **Medium**, **Medium large**, **Large**, or **Extra large**. Font-size labels are translated when using **Slovak (Slovenčina)**. Existing saved font-size and language selections remain compatible.

Option dialogs apply a selection immediately and dismiss. **Cancel** dismisses without selecting a different option. Selected radio indicators have an accent outline and an inner accent square; their outer dimensions match unselected indicators.

**About Koda** shows app version and project information and has an **OK** dismissal button.

## Dialog presentation

Dialogs share the settings background, a visible border, square corners and horizontal screen margins. Titles, content and actions use consistent spacing. Two-button dialogs distinguish the primary action from the secondary action; button backgrounds and press feedback remain square. Long action labels stack vertically when they cannot fit side by side.
